LLM Wiki

A pattern for building personal knowledge bases using LLMs.

Instead of retrieving fragments from raw documents for every question, an agent can maintain a persistent wiki. When a new source arrives, the agent reads it, extracts useful information, and integrates it with existing topic pages. The wiki becomes a structured, interlinked layer between original sources and future questions.

Architecture

The system has raw sources, the maintained wiki, and a schema that describes its conventions. Sources remain immutable. The wiki is updated as new material arrives, while the schema explains how the agent should ingest, query, and maintain that material.

Operations

Ingest one source at a time, review the resulting synthesis, and keep a chronological log of important changes. Queries can produce notes, comparisons, charts, or other useful artifacts that are filed back into the wiki. Periodic linting looks for contradictions, stale claims, and missing cross references.
