# Understand Bob

Eight nouns carry the whole system. Start with the diagram, then read each
idea and the glossary for exact meanings.

## The nouns

- **Vault** — one Obsidian folder of Markdown; the authoritative state the tools reconcile.
- **Task** — a `#task` checkbox line with block ID and date fields; see [Tasks and lanes](tasks-and-lanes.md).
- **Lane** — Ready, Next, Pending, Blocked, Done, Cancelled; sticky except Blocked, which is derived; see [Tasks and lanes](tasks-and-lanes.md).
- **Pomodoro** — a timed work session in the daily note under `## Pomodoros`; see [Today and the Pomodoro ledger](today-and-the-pomodoro-ledger.md).
- **Capture** — one `bob capture` draft that plans edits then writes all or nothing; see [Tasks and lanes](tasks-and-lanes.md#capture-makes-a-task).
- **Freshness** — the local calendar date a human last confirmed a task; see [Freshness and the review walk](freshness-and-the-review-walk.md).
- **Project** — a note whose `^prj` task states the outcome; residents follow its blocking; see [Projects and dependencies](projects-and-dependencies.md).
- **Plugin** — an Obsidian extension that renders review and writes gestures into the vault; Mac Capture is a sibling program that submits drafts through the CLI.
