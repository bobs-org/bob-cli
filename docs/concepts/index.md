# Understand Bob

Eight nouns carry the whole system. Start with the diagram, then read the
glossary for exact meanings.

## The nouns

- **Vault** — one Obsidian folder of Markdown; the only state Bob keeps.
- **Task** — a `#task` checkbox line with block ID and date fields.
- **Lane** — Ready, Next, Pending, Blocked, Done, Cancelled; sticky except
  Blocked, which is derived.
- **Pomodoro** — a timed work session in the daily note under `## Pomodoros`.
- **Capture** — one `bob capture` draft that plans edits then writes all or
  nothing.
- **Freshness** — the local calendar date a human last confirmed a task.
- **Project** — a note whose `^prj` task states the outcome; residents follow
  its blocking.
- **Plugin** — desktop Obsidian or Mac surfaces that read the vault; the CLI
  owns capture semantics and vault writes.
