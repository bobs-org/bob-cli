# Glossary Terms

Run `sase memory read glossary:<term> [<term> ...] -r "<why>"` before relying on any of these SASE terms; it prints each term's definition plus every term those definitions depend on. Pass every term you need in one command — one batched read costs far fewer tokens than one read per term, because terms shared between definitions are printed once. Terms are separated by semicolons; aliases follow in parentheses.
