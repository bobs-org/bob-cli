# Task Split

aka split, split out

Task Split promotes selected notes from a parent task into newly born tasks. The parent
keeps live checkbox links to the new tasks as stubs, and each new task gets a generated
mention back-link; split does not write a `split from` relation. Use `bob task split` or
Ctrl+Shift+T; see `docs/task-split.md` for the contract and exact edits. This promotes
task notes into task identities, distinct from splitting one [[pomodoro]] session's
time record.
