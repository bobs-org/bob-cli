When the `<ctrl+shift+p>` Obsidian keymap is used to add the `scheduled` or `priority` dataview property to a task — Task Card `1`–`4` picks a P-level and its frozen date, Enter opens explicit Schedule, and classic search (`/` or type to filter) reaches the same properties — or when `bob capture` uses `p:<N>`, we add a `SCHEDULE LOG` bullet that contains one sub-bullet for each scheduling. Log grammar, opt-in markers, and blank-reason `🤷 no reason given` are unchanged.
