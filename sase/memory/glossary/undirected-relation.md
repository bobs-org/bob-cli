# Undirected Relation

*Requested · project*

A [[task-relation]] with no label. It says only that two tasks belong together, so it has
no direction. Both tasks show each other under `🪢 links`, and linking them again from
either end changes nothing. Adding a label turns it into a [[directed-relation]]. Two
tasks that already share a directed relation need no plain link.
