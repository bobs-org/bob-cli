A [[property-card]] (formerly the record sheet) Bob Ledger Tools paints in the
title slot of a canonical album [[record-note]] in desktop Reading view and
Live Preview, replacing in-document native Properties when the card and foot
mount, valid source matches the cache, `props_v1` is confirmed, and editor
routing is ready. A sheet tile and a `RECORD` kicker naming the
parent album lead the title, which paints from local metadata before any report.
Whenever the card owns the title, the inline title and a matching first-body H1
or walk line hide at render time, and a Live Preview cursor reveals the raw line.
The foot carries the created stamp; the `-` drawer and `+` Property Editor
inventory every key, including identity, legacy, and unrelated values.
Without whole ownership, existing album-schema row hiding remains when
eligible; failed mounts and denied contexts restore native rendering. The
Record Card editor (`==`) remains the keyboard-first editor for the record's
values. A recognized walk line becomes a rail docked inside the card with the album-ring
position. The card reads the cached album report: opening, folding, or
collapsing a record never requests a new report and never writes the note.
Source mode keeps native YAML, and the File Properties sidebar stays native.
See `docs/reference/plugins/record-card.md` and
`docs/reference/plugins/property-editor.md`.
