# Task Relation

*Requested · project*

An inert link between two tasks: an [[undirected-relation]] when it has no label, and a
[[directed-relation]] when it has one. It is authored once on one task's 🪢 **LINKS:**
line and mirrored on the other's generated 🪢 **LINKED FROM:** line. Which task stores
a plain link carries no meaning. Add one with Capture `~` (or `~~` with a label) or the
Task Card `l` gesture. A relation is distinct from a Pomodoro [[task-link]] and a
[[task-dependency-link]]: it never blocks a task, counts as a Pomodoro Task Link, or
changes its status, schedule, priority, or freshness.
